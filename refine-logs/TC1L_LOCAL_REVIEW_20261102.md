## Local memory and arithmetic pitfalls

1. A float32 full 57,638x768 gallery is 177,063,936 data bytes (about 168.9 MiB); old documents and paid targets each use about 84.4 MiB. This is feasible with sequential disk-backed storage, but repeated hidden copies can dominate the laptop's observed low free RAM. `mmap_mode='r'` alone does not prevent temporary allocations.
2. Existing `exact_topk` calls `_vectors`, whose full-matrix finite/norm checks allocate large temporaries; existing runner retains all four unpaid galleries and converts one to float64. The local runner must validate gallery/source/paid targets in bounded row blocks and compute diagnostics in bounded blocks. Keep the original inference expression: 512-row float32 augmented matrix `x @ coef`, then the original row normalization. Do not substitute `old @ W + intercept`, float64 inference, algebraically equivalent solver changes, or document-block retrieval.
3. Preserve one full-document score matrix per query batch of 16: `q[start:start+16] @ gallery.T`, then descending stable `argsort`. The score output is only about 3.52 MiB for a full batch; the stable-sort index array is about 7.04 MiB on 64-bit Python. Document chunking or per-block top-k can change BLAS arithmetic and near-tie rankings. Exact equal scores retain original row order. Explicit identical-ID exclusion happens before sorting.
4. Paid overwrite must use exact original float32 rows in their sorted document-index alignment. Validate paid targets only after slicing authorized paid50 rows. Never normalize paid targets again or include anchors as an additional cost. Raw full-target bytes may be streamed for SHA256; numerical full-target scans, norm checks, summaries, or normalization would exceed logical exposure. Anchor lookup must preserve the original anchor order rather than sort anchors.
5. Do not retain four gallery arrays for unpaid diagnostics. Recompute tiny affine blocks from saved final coefficients for paired comparisons (or use a documented disk-backed equivalent), mask out paid rows within each block, and accumulate continuous maxabs/angular diagnostics and equality indicators. Quantile input vectors of one scalar per unpaid row are small. Compare C-T radial identity at a shared state, not across diverged trajectories. Preserve legitimate near-zero effects; an exact unpaid T/control identity follows the original smoke STOP.
6. Windows file mappings need explicit reference cleanup before file moves/deletion or reuse. Flush any writable map before hashing and sealing. Use unique stage/cell artifacts; a failure cannot be resumed by overwriting. Chunked hashes are byte operations, not target numerical access. Record both physical cache provenance and 28,819 logical paid rows, with zero new encodings.
